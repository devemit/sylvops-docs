# Roadmap

::: info PLANNED — Everything on this page is planned
These items are not available in the current public preview. Do not rely on them when choosing or operating SylvOps today.
:::

## Git and hosting workflows

- Explicit import of externally created Git worktrees
- GitHub integration
- Commit actions
- Push actions
- Pull-request creation and management
- Rich commit and branch history tools

## Navigation and discovery

- File finder
- Git grep
- Expanded history presentation and pruning

## Providers and execution

- Claude cloud sessions, background-agent management, Remote Control, plugins, and enterprise authentication
- Remote execution
- Additional provider adapters after the same safety and recovery requirements are met

## Coordination

- Desktop notifications
- More ways to surface agent attention without scraping terminal output

## Distribution

- Official signed `v0.1.0` release
- Linux package signing
- Signed native Windows installer and signed in-app updates in a published official release
- Signed and notarized macOS packages in a published official release

Roadmap order can change. A feature becomes current only when the source, tests, release artifacts, and public documentation agree.
